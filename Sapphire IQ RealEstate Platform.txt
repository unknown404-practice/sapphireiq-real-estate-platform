PROJECT OVERVIEW
01 / PROJECT OVERVIEW
RealEstate Platform
A real estate website with listings and booking, and an optional AI search add-on.
Project Description
Students build a real estate platform for India with a user website and a REST API.
Users browse and filter properties, list their own, and book viewings. As an optional
bonus, an AI Property Hub can search live listings from property portals and rank the
best matches.
Project Scope
Core: JWT authentication with password reset by email, property CRUD with multi-
image upload, filters and gallery, guest and logged-in booking, a user dashboard,
security and deployment. Optional: the AI search pipeline, kept behind a feature switch.
Prerequisites
React and TypeScript: Components, hooks, props and types.
Express and MongoDB: REST APIs, Mongoose and JWT auth.
Async JavaScript: Promises, async/await and error handling.
Accounts: MongoDB Atlas, ImageKit and an email (SMTP) service. Only for the optional AI module: a Firecrawl free key.
Target audience: Intermediate to advanced students who have finished at least one full stack project with authentication.

MODULE 5
06 / MODULE 5
Optional Bonus: AI Property Hub
Build the RealEstate platform step by step using React, TypeScript, Node.js, Express and MongoDB.
Learning Objectives
Add the AI search only after the core platform works.
Scrape individual listing pages and rank results with an
AI model.
Keep the feature switchable so the app works without
it.
Core Concepts
Search to Scrape: find listing URLs first, then scrape
each page.
Deduplicate and Filter: remove repeats and rentals in
code.
Bring Your Own Key: the user's scraping key is sent in
a request header.
Retry with Backoff: handle rate limits and server errors.
Feature Flag: a setting such as
VITE_ENABLE_AI_HUB turns the AI feature on or off.
Tools & Technologies
Firecrawl
AI model API
Axios
localStorage
Hands-on Student Exercises
Optional: Search for a 2BHK flat in a city, view ranked results with source badges, and trigger a rate-limit error to see the retry work. Then switch the feature off and confirm the rest of the
app still works.
